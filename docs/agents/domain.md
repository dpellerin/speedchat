# Domain Docs

SpeedChat uses a single-context layout.

- Read the root `GLOSSARY.md` and any relevant decisions under `docs/adr/` before exploring the code. Proceed with the available documentation if either location is absent.
- Use the glossary's terms in issue titles, proposals, hypotheses, and test names. Bring genuine vocabulary gaps to the domain-modeling skill.
- If a proposal conflicts with an ADR, name the ADR and explain why the decision may need revisiting.

Use the domain-modeling skill to add glossary entries and ADRs as terms and decisions are settled.
